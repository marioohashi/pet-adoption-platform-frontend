# 🐾 Responsible Pet Adoption Platform — Frontend

Frontend application for the Responsible Pet Adoption Platform — a modern, responsive interface built to connect NGOs, donors, and adopters in a safe and intuitive environment.  
Developed with **React, TypeScript, Tailwind CSS, React Query, Zod**, and **Zustand**.

---

## 🌟 Overview

This frontend delivers a clean, accessible, and user-friendly experience for browsing pets, managing NGO dashboards, and completing the adoption workflow.  
It emphasizes UI/UX quality, component reusability, and smooth interactions.

---

## 🧱 Tech Stack

- React.js  
- TypeScript  
- Tailwind CSS  
- React Query  
- Zod (form validation)  
- Zustand / Context API  
- Axios  
- Vite

---

## 📌 Core Features

### 🔐 Authentication
- Login & registration  
- Role-based UI (adopter, donor, NGO)  
- Zod validation for all forms

### 🐶 Animal Listings
- Beautiful card-based UI  
- Photo gallery & details page  
- Filters: species, breed, age, size, behavior, location

### 🏢 NGO Dashboard
- Manage animals  
- Publish events & campaigns  
- View adoption requests

### 📨 Messaging
- Secure chat between adopters and NGOs  
- Real-time updates (optional WebSocket integration)

### 🎨 UI/UX Highlights
- Fully responsive  
- Tailwind-based design system  
- Reusable components  
- Smooth microinteractions  
- Accessible color palette  
- Optional dark/light mode
